# CreateCardDialog

Этот пример добавления в диалог создания карточки пользовательского типа.

## Настройка среды  

Пример рассчитан на версию Web-клиента 18 (6.1) или выше.

**Перечень необходимых инструментов:** 
* [Visual Studio 2022](https://www.visualstudio.com)
* [NodeJS v22.14.0+](https://nodejs.org/en/)
* [WiX Toolset v3+](https://www.firegiant.com/wixtoolset/)

## Сборка

1. Открыть консоль в каталоге Others\NetStatSolution\NetStatSolutionWebExtension и выполнить команду npm install, потом  npm run build:prod
2. Открыть /Samples.sln
3. Собрать проект Other > NetStatSolution > CardLib
4. Собрать проект Other > NetStatSolution > NetStatSolution.ObjectModel
5. Собрать проект Other > NetStatSolution > NetStatSolution.Cards
6. Собрать проект Other > NetStatSolution > NetStatSolutionServerExtension
7. Собрать проект Other > NetStatSolution > NetstatSolutionClientInstaller
8. Собрать проект Other > NetStatSolution > NetstatSolutionInstaller

## Проверка примера

1. Установить серверную часть решения ("Others\NetStatSolution\Installers\ru-ru\NetstatSolution.msi) на сервер. Для корректной работы примера Сервер приложений и Клиент должны быть установлены на одной машине
2. Обновить базу данных
3. Установить клиентскую часть решения
4. Запустить конструктор разметок
5. Импортировать решение из каталогаOthers\NetStatSolution\Solution
6. Выбрать библиотеку "NetStatSolution карточки"
7. Выбрать тип "Карточка учета сетевого оборудования"
8. Убедиться, что для выбранного типа присутсвуют разметки создания, просмотра и редактирования, а так же для них заданы условия выбора
9. Разрешить создание карточек вида "Карточка учета сетевого оборудования" в справочнике видов карточек
10. В Консоли управления на странице конфигурации Web-клиента задать идентификатор типа карточки учета сетевого оборудования. (Редактор "Типы карточек, отображаемые в диалоге создания", идентификатор — CCCA40C0-5FA4-4878-B0DA-34E67E167BEA, CSS-класс — netstat)
11. Перезапустить сервис Web-клиента
12. Открыть Web-клиент и нажать на кнопку "Создать"
13. Должен появиться новый тип карточки "Карточка учёта сетевого оборудования", доступный для создания (фон - фиолетовый).
14. При выборе его, открывается созданная разметка, при этом фон боковой панели и шапки становится фиолетовым.

## Проект CardLib

Проект описывает библиотеку карточек. Описывает входящие в неё типы карточек и их схему.

## Проект NetstatSolution.ObjectModel

Проект описывает объектную модель карточек, входящих в библиотеку решения.

## Проект NetstatSolution.Cards

Проект содержит компоненты карточек для взаимодействия с Windows-клиентом.

## Проект NetStatSolutionServerExtension

Проект реализует серверное расширение, в котором регистрируется фабрика для создания типа карточки "Карточка учёта сетевого оборудования", отличная от стандартной. 

## Проект NetStatSolutionWebExtension

Содержит расширение Web-клиента для добавления кнопки создания карточки учёта сетевого оборудования в диалог создания карточек
